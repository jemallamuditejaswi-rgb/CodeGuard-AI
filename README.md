
# 🛡️ CodeGuard AI

## AI-Assisted Python Code Review and Bug Detection

CodeGuard AI is a Python code analysis tool built using Streamlit and Ruff. It helps users identify code-quality issues, detect runtime errors, understand error explanations, and apply supported automatic fixes.

## Features

- Python syntax checking
- Code-quality analysis using Ruff
- Runtime error detection
- Error explanations and severity levels
- Automatic fixing of supported code-quality issues
- Original and fixed code comparison
- Downloadable analysis report
- Downloadable fixed Python file

## Technologies Used

- Python
- Streamlit
- Ruff

## How to Run

1. Install Python.
2. Open the project folder in the terminal.
3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL shown in the terminal.

## Safety Notice

Run only trusted Python code. This application executes submitted code on your computer and is not a secure sandbox.
